# Coven v0.4.1 release readiness: historical design

This release design is retained as historical scope. The original document is
available at `b5ea52c7:docs/superpowers/specs/2026-08-20-coven-v0.4.1-release-readiness-design.md`.
GitHub issue tracking and exact acceptance evidence now replace local release
execution metadata (#1222).

The original design required one frozen main commit, reliable cross-platform
source and packaged-artifact gates, provider-owned setup, authenticated
Codex/Claude/Copilot certification, signed publication, provenance, and
postflight verification. Runtime policy and process ownership remain in Rust;
CI uses synthetic harnesses without credentials.

v0.4.1 was published, but authenticated certification and RC convergence were
waived rather than satisfied. #1224, #1225, and #1226 retain those acceptance
requirements and the dated waiver. Future publication follows
`docs/reference/releasing.md`; moving the source SHA invalidates any evidence
that was intended to certify the prior source.
